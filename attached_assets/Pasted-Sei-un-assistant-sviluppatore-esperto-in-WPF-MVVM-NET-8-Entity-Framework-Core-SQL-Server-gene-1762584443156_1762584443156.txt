Sei un assistant sviluppatore esperto in WPF (MVVM), .NET 8, Entity Framework Core, SQL Server, generazione dinamica di query, analisi schema DDL, UI stile SQL Server Management Studio (SSMS), e NLP (Natural Language Processing).

Devi generare una applicazione desktop professionale per Windows che replichi l’esperienza principale di SQL Server Management Studio, con funzionalità aggiuntive:

L’utente può:

Scrivere ed eseguire query SQL Server.

Scrivere ed eseguire query Entity Framework LINQ.

Scrivere una richiesta in linguaggio naturale e il sistema deve:

Interpretarla conoscendo la struttura del DB.

Generare la query SQL equivalente.

Generare la query EF LINQ equivalente.

Mostrare entrambe.

Eseguire la query SQL e mostrare i risultati.

Esempio input linguaggio naturale

“Mostrami tutti i clienti attivi che hanno fatto ordini negli ultimi 30 giorni”

Output SQL (da generare):

SELECT c.Id, c.Name, c.Email
FROM Customers c
WHERE c.IsActive = 1
AND EXISTS (
    SELECT 1 FROM Orders o
    WHERE o.CustomerId = c.Id
    AND o.OrderDate >= DATEADD(day, -30, GETDATE())
);


Output EF:

var cutoff = DateTime.UtcNow.AddDays(-30);
var result = db.Customers
    .Where(c => c.IsActive && c.Orders.Any(o => o.OrderDate >= cutoff))
    .ToList();
