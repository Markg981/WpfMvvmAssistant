## 2026-06-09 - Static vs Dynamic Regex Compilation
**Learning:** In the `RuleBasedNaturalLanguageTranslator`, compiling static regex patterns (like 'top', 'first', and 'last X days') with `RegexOptions.Compiled` provides a significant performance boost (approx 90% faster than dynamic `Regex.Match` calls). However, compiling dynamic regex patterns (those injecting variables like `columnName` inside loops) using `RegexOptions.Compiled` is a severe performance anti-pattern that leads to regex compilation memory leaks and recompilation overhead.
**Action:** Always deliberately distinguish between static and dynamic regex patterns. Extract frequently used static patterns into `private static readonly Regex` instances with `RegexOptions.Compiled`. Keep dynamic patterns uncompiled using standard `Regex.Match` calls.
