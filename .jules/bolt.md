## 2024-05-18 - Regex Compilation Anti-Pattern
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a severe performance anti-pattern due to excessive recompilation overhead. Standard `Regex.Match` calls should be used for dynamic strings. Conversely, performance-critical static regex patterns (like 'top', 'first', and 'last X days') should be implemented as `static readonly Regex` instances with `RegexOptions.Compiled` to avoid repeated compilation overhead. Benchmarking showed this static approach is approximately 90% faster than dynamic `Regex.Match` calls for static patterns.
**Action:** Always extract static performance-critical regex patterns into `static readonly Regex` fields with `RegexOptions.Compiled`. Never use `RegexOptions.Compiled` for dynamically constructed regex strings inside loops; just use standard `Regex.Match`.
