## 2024-05-24 - Distinguishing Static vs. Dynamic Regex Patterns
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a severe performance anti-pattern. However, performance-critical static regex patterns (like "top", "first", and "last X days" in natural language translation) should be implemented as `static readonly Regex` instances with `RegexOptions.Compiled` to avoid repeated compilation overhead. Benchmarking showed this approach is approximately 90% faster than dynamic `Regex.Match` calls. Dynamic regex patterns (e.g., those injecting variables like column names) must deliberately remain uncompiled (standard `Regex.Match`) to avoid regex compilation memory leaks.
**Action:** When optimizing regex matching, carefully distinguish between static and dynamic patterns. Compile static patterns as static readonly fields, but leave dynamic patterns (especially inside loops) as standard `Regex.Match` calls.
