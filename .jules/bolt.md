## 2024-05-24 - Optimize Regular Expression Evaluation in Loop
**Learning:** In the `RuleBasedNaturalLanguageTranslator`, dynamically invoking `Regex.Match` inside tight loops causes repeated compilation overhead. However, while extracting performance-critical static regex patterns (like 'top', 'first', and 'last X days') into `static readonly Regex` instances with `RegexOptions.Compiled` is extremely beneficial (benchmarks show ~90% improvement), doing the same with dynamic patterns inside loops using `RegexOptions.Compiled` is a severe performance anti-pattern. This is because dynamic patterns generate massive GC pressure and repeated IL generation overhead, destroying performance.
**Action:** Extract constant static regex strings into `private static readonly Regex` fields using `RegexOptions.Compiled`. Keep dynamic patterns inside loops as standard `Regex.Match` calls without the `RegexOptions.Compiled` flag to avoid the recompilation overhead and GC pressure.
