## 2024-05-24 - [Regex Compilation Overhead in NLP Translator]
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a severe performance anti-pattern and can cause memory leaks. However, for static performance-critical patterns (like 'top', 'first', and 'last X days'), using `static readonly Regex` instances with `RegexOptions.Compiled` is extremely beneficial and avoids repeated compilation overhead (benchmarking showed ~90% improvement). Dynamic patterns must deliberately remain uncompiled (`Regex.Match`).
**Action:** Always extract static regex patterns into `static readonly` fields initialized with `RegexOptions.Compiled`. Keep dynamic regexes (e.g., those injecting variables like `columnName`) as standard uncompiled `Regex.Match` calls to balance performance and memory safety.
