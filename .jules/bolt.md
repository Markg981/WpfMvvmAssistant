## 2024-04-08 - Regex Compilation Anti-Pattern in NLP Translator
**Learning:** In the `RuleBasedNaturalLanguageTranslator`, performance-critical regex patterns (like 'top', 'first', and 'last X days') were being dynamically compiled inside parsing loops using `Regex.Match()`. This caused a significant performance penalty due to repeated compilation overhead. Benchmarking showed that using `static readonly Regex` instances with `RegexOptions.Compiled` is approximately 90% faster. However, dynamic regex strings (such as those constructed dynamically per column using string interpolation) must NOT use `RegexOptions.Compiled` inside a loop, as doing so would cause severe recompilation overhead and exhaust memory/cache.
**Action:** When working on parsing loops or NLP code, extract static regex patterns to `static readonly Regex` fields with `RegexOptions.Compiled`. Retain standard `Regex.Match` for dynamically constructed regex strings inside loops.
