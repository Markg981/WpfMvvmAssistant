## 2024-05-18 - Avoid re-compiling static Regex patterns in NLP
**Learning:** The RuleBasedNaturalLanguageTranslator used on-the-fly Regex compilation (Regex.Match with string arguments) inside its QueryParser. This introduces unnecessary memory allocation and compilation overhead on every query, scaling poorly when translating NLP to SQL for numerous table scans. Dynamic regular expressions based on variables, however, shouldn't use RegexOptions.Compiled because compiling different regex strings repeatedly will cause severe CPU overhead and memory leaks.
**Action:** Always precompile constant Regex expressions using static readonly fields with RegexOptions.Compiled. Only use Regex.Match with string patterns for dynamically generated expressions, and do not compile those if they vary continuously.
