## 2024-05-15 - Regex compilation memory leak pattern
**Learning:** In `RuleBasedNaturalLanguageTranslator`, performance-critical regex patterns (like 'top', 'first', and 'last X days') should be implemented as `static readonly Regex` instances with `RegexOptions.Compiled` to avoid repeated compilation overhead. Benchmarking showed this approach is approximately 90% faster than dynamic `Regex.Match` calls. However, dynamic regex patterns (e.g., those injecting variables like `columnName` inside loops) must deliberately remain uncompiled (standard `Regex.Match`) to avoid regex compilation memory leaks and severe performance degradation, distinguishing them from static regex patterns.
**Action:** When optimizing Regex usage in C#, separate static patterns from dynamic patterns. Use `RegexOptions.Compiled` on static fields for static patterns, but use regular uncompiled `Regex.Match` for dynamically constructed patterns.
