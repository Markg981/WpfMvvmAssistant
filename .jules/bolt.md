## 2024-05-24 - Regex Performance Pattern in RuleBasedNaturalLanguageTranslator
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a performance anti-pattern due to severe recompilation overhead. However, static regex patterns like 'last X days', 'top', and 'first' can and should be compiled as `static readonly Regex` instances with `RegexOptions.Compiled` to avoid repeated compilation overhead. Benchmarking showed this approach is approximately 90% faster than dynamic `Regex.Match` calls.
**Action:** Always extract static string patterns into compiled static readonly `Regex` instances. Leave dynamically generated string patterns (e.g., interpolated with loop variables) as standard `Regex.Match` calls to avoid the caching/recompilation penalty.
