## 2024-05-24 - Pre-compile Static Regex Expressions
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` or relying on inline `Regex.Match` for static patterns is a performance anti-pattern. Benchmarking showed that using `static readonly Regex` instances with `RegexOptions.Compiled` is approximately 90% faster than dynamic `Regex.Match` calls for fixed patterns. Standard `Regex.Match` calls should only be used for dynamic strings to avoid severe recompilation overhead.
**Action:** When using regex for static patterns (like 'top', 'first', and 'last X days' in `RuleBasedNaturalLanguageTranslator`), always extract them into `private static readonly Regex` fields initialized with `RegexOptions.Compiled`. Do not use `RegexOptions.Compiled` on dynamically constructed patterns.
