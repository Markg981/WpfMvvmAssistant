## 2024-06-10 - Regex Compilation Performance in NLP Translator
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a severe performance anti-pattern. While static regex patterns (`last X days`, `top X`) benefit significantly (~90% faster) from compilation, dynamic patterns (e.g., those injecting variables like `columnName` in `RuleBasedNaturalLanguageTranslator`) must remain uncompiled (standard `Regex.Match`) to avoid regex compilation memory leaks and massive schema-related allocations.
**Action:** When optimizing regex performance, distinguish between static and dynamic patterns. Apply `static readonly Regex` with `RegexOptions.Compiled` ONLY to patterns that are static at compile time. Leave dynamic patterns that vary at runtime as standard `Regex.Match` calls.
