## 2024-06-18 - [Optimize static regex patterns]
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a severe performance anti-pattern leading to memory leaks. However, extracting static regex patterns (like 'top', 'first', 'last X days') into `static readonly Regex` instances with `RegexOptions.Compiled` at the class level avoids repeated compilation overhead and is approximately 90% faster. Dynamic regex patterns injecting variables (e.g., `columnName`) must deliberately remain uncompiled (standard `Regex.Match`) to avoid regex compilation memory leaks.
**Action:** Always identify and isolate static vs dynamic regex patterns. Compile static patterns using `static readonly Regex` with `RegexOptions.Compiled`, but keep dynamic patterns inside loops as uncompiled `Regex.Match` calls.
