## 2024-05-18 - [Optimizing Dynamic Regexes in WPF]
**Learning:** Compiling dynamic regex patterns inside a loop using `RegexOptions.Compiled` is a performance anti-pattern. Standard `Regex.Match` calls should be used for dynamic strings to avoid severe recompilation overhead. However, for static performance-critical regex patterns like 'top', 'first', and 'last X days', using `static readonly Regex` instances with `RegexOptions.Compiled` avoids repeated compilation overhead and improves performance.
**Action:** Extract performance-critical static regex patterns into `static readonly Regex` instances with `RegexOptions.Compiled` when they are used inside loops or repeatedly parsed. Keep dynamic strings as normal `Regex.Match` calls to avoid `RegexOptions.Compiled` compilation penalties.
